# Logos

`botspace-logo-white.svg` is the BotSpace mark in white ink (`#ffffff`). Put it on a `primary` square: 32 px with 6.4 px corners (`radius-md`) in the rail, the mark at 16 px. In dark mode `primary` turns light, so invert the mark there (`dark:invert`). Do not recolour it, stretch it, or put it on a tonal fill.
